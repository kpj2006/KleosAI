## KleosAI
An Intelligent Financial Companion for Smarter Student Spending

## Problem Statement

Most students do not struggle with money because they are irresponsible.

They struggle because **money leaks silently**:

* Subscriptions
* Digital micro-payments
* Impulse purchases
* Forgotten expenses

Traditional finance apps only answer: “Where did my money go?”

They do **not** help with:“Should I spend this right now?”

##  What is KleosAI?

KleosAI is an **AI-powered financial companion** that helps users:

* Understand their financial health instantly
* Make smarter decisions *before* spending
* Build sustainable money habits

## Key Features

### Smart Purchase Validator

Ask *“Can I afford this?”* before buying.
KleosAI analyzes balance, habits, and goals to label purchases as **Viable** or **Risky**.

### Goal Tracking

Set goals (laptop, travel, emergency fund).
See progress, time required, and monthly savings needed.

### Transaction Visualization

Spending is grouped into clear category columns for instant pattern recognition.

### Fast Onboarding

Upload transactions via `.json` file (which is issued by almost all banks as transactions statement) for quick setup and immediate insights.

### Behavioral Insights

AI analyzes habits and explains *why* you spend the way you do — not just how much.

## Key terms

Instead of overwhelming charts and tables, users see a **clear financial snapshot**:

* **Stability Index** – Overall financial health score
* **Safety Buffer** – How protected the user is against emergencies
* **Monthly Surplus** – How flexible their spending really is

## Tech Stack
* Frontend: Next.js,React,CSS
* Backend: Node.js
* Database: firebase as login only and localdb for user data
